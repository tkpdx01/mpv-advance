● mpv-advance 监控播放器

多路分割网格 · 可搜索摄像头菜单 · 实时/回放切换 · 按墙钟时间的时段回放 · 常驻窗口

快速开始

双击一键启动脚本即可（会自动拉起 mock API 并启动播放器，关窗后自动清理）：

surveillance\launch.cmd

或手动分两步：

# 1) 启动 mock 摄像头 API（默认 127.0.0.1:8777）
python surveillance/api/mock_camera_api.py --port 8777

# 2) 用便携配置启动 mpv
mpv --config-dir=surveillance/portable_config
API 不可用时脚本自动回退读取 data/cameras.json，功能不中断。覆盖层右上角显示当前数据源为 API 还是 本地。

如何选择摄像头

  1. 先按数字键 1…9（或 TAB）选中要操作的画格——覆盖层上会出现高亮边框
  2. 按 c 打开摄像头列表
  3. 直接打字即模糊搜索（名称 / 分组 / 位置 / ID / 标签都能匹配），↑↓ 移动，回车 确认
  4. 选中的摄像头填入刚才那个画格

想一次填满整个网格，不用逐个选，直接按 Ctrl+a 自动填充（在线优先）。

如何回放时段

按 k 打开时段回放菜单，五类选项：

选项说明
⏱ 预设时段最近 5 / 15 / 30 分钟、最近 1 小时、今天 00:00、昨天 00:00，选中直接跳转
🗓 自定义时间输入 YYYY-MM-DD HH:MM，或只写 HH:MM 表示今天
⚑ 按事件跳转列出该摄像头事件（移动侦测 / 人形 / 越界 / 车辆 / 逗留），选一条定位到那一刻
🔁 A-B 循环片段在当前位置设 A 点、B 点，反复循环查看某一段
🎚 播放微调等同 K，±10/60 秒或 25/50/75% 定位
两点注意：
1. 进入时段回放会自动切成单画面重要——多路网格共用一条时间轴，无法逐路 seek，单画面才能精确定位。所以按 k 之前，先用 1…9 选好要回放哪一路。
2. 片段播完停在末帧不退出（常驻）。看完想回实时，菜单选「● 返回实时 LIVE」或直接按 l。

典型流程

3 选第 3 路  →  k 时段回放菜单  →  选「最近 15 分钟」  →  自动单画面定位播放  →  看完 l 回实时

常驻不退出

mpv.conf 通过三项叠加保证播放器常驻：idle=yes（无文件也保活）、force-window=yes（始终显示窗口）、keep-open=yes + keep-open-pause=yes（播放结束停在末帧并暂停）。实时模式循环样本模拟持续画面；回放模式片段播完停末帧等待下一步。
